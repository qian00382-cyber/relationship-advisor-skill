# 关系判断与聊天回复参谋

融合关系证据判断、迷男方法的阶段与校准框架，以及自然、有分寸的聊天回复。

## 能做什么

- 判断关系：区分事实、解释和未知，观察双方投入与明确表达。
- 分析阶段：参考 M3 的吸引、舒适与信任、双方自愿的亲密，不把模型当定律。
- 帮你回复：按真实意图给一句自然、可直接发送的消息。

不读心、不打压、不把拒绝解释为欲擒故纵。不保证关系结果。

## 下载与使用

在 GitHub 仓库页面选择 **Code → Download ZIP**，解压后使用 `SKILL.md`。

支持 Agent Skills 的工具：将 `SKILL.md` 放进 `relationship-advisor` 文件夹，再放到工具支持的 skills 目录。例如 Claude Code 可使用 `.claude/skills/relationship-advisor/SKILL.md`。

ChatGPT：可将 `SKILL.md` 的内容粘贴到自定义 GPT 的“指令”中。下载或上传 ZIP 本身不会自动安装或全局启用技能。

## 调用示例

> 帮我分析这段聊天，判断我们目前的关系，再给我一句自然的回复。

> 用迷男方法分析当前互动的阶段，区分事实与推测，告诉我怎么回。

本项目并非 Mystery 官方作品，也不是完整复刻。框架主要参考 *The Mystery Method*（2007），仅将阶段、真实自我展示与反馈校准用于辅助分析。
